# Sprint09 회고

> 이번 스프린트 돌아보기

이번 스프린트는 14일 중에 12일을 채웠다. 지난 스프린트의 7일에서 다시 올라왔다.

지난 회고에서 단디를 중심으로 목표를 다시 잡겠다고 했는데, 이게 꽤 잘 맞았던 것 같다. 목표에 단디 기능들을 앞에 두니까 매일 무엇을 해야 할지가 명확했고, 하루를 시작할 때 고민하는 시간이 확실히 줄었다.

이번 스프린트에서 한 것들을 보면

- 식사 기록 및 영양 분석 비동기 설계 / 구현 (Outbox Pattern, 폴링 워커)
- AWS 이관 및 Jenkins 재배포 검증
- 구글 / 네이버 OAuth 로그인
- Grafana Cloud 관측 도입 (메트릭 / 트레이스 / 로그 / 프로파일)
- 문의함 API, 공통 헤더, 에러 핸들링 세분화

설계하고, 구현하고, 배포하고, 관측하는 것까지 한 바퀴를 직접 돌아본 스프린트였다. 처음으로 "서버를 운영한다"는 느낌을 받았다.

> 공부하는 방식이 바뀌었다

CS 면접을 CS Daily로 바꾸고, 궁금한 게 생기면 그걸 끝까지 파고드는 방식으로 공부하고 있다.

namespace, Virtual Memory, paging, segmentation, swap, thrashing까지 하나를 보면 그 다음이 궁금해져서 계속 이어졌다. 그냥 외우는 것보다 이게 훨씬 재미있고 오래 남는 것 같다.

> 아쉬운 점

반대로 목표에 있던 JPA 강의는 이번에도 손을 못 댔다. Real MySQL, 시스템 설계 수업도 조금씩 읽긴 했지만 진도가 많이 나가진 못했다.

JPA는 벌써 몇 스프린트째 이월되고 있는지 모르겠다. 이쯤 되면 정말 들을 건지, 아니면 단디에서 필요한 부분만 찾아서 볼 건지 확실하게 정해야 할 것 같다.

이번 스프린트에서 만든 것들을 실제로 운영하면서 생기는 문제들을 마주하게 될 것 같다. 그리고 그 과정에서 겪은 것들을 블로그와 이력서에 꼭 남기자.

다음 스프린트도 그냥 하자.
