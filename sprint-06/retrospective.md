# Sprint06 회고

> 이번 스프린트 돌아보기

이번 스프린트는 14일 중에 11일을 채웠다. 숫자만 보면 나쁘지 않은 스프린트였다고 생각한다.

첫째 주는 AWS 교육 (Architecting on AWS, Agentic AI)이 매일 잡혀 있었는데, 그 와중에도 CS 면접이랑 백엔드 실습 과제는 거의 하루도 빼먹지 않았다. 아침에 끝내야 하는 것들을 아침에 끝내자는 지난 스프린트의 다짐이 어느 정도는 지켜진 것 같아서 이 점은 칭찬해주고 싶다.

그리고 드디어 스프링 DB 2편을 끝냈다. 트랜잭션 전파까지 들으면서 그동안 그냥 붙이던 `@Transactional`이 어떻게 동작하는지 조금은 알게 된 것 같다.

> 그런데 JPA는?

지난 스프린트 회고에서 DB 2편, JPA 1, 2, 3편을 **무조건** 수강 완료해야 한다고 적었었다.

결과는 DB 2편 하나였다. JPA는 시작도 못했다.

왜 못했을까 생각해보면, 하루에 하는 일의 가짓수가 너무 많았던 것 같다. CS 면접, 백엔드 실습, 코테, 스파클링, 단디, AWS 교육, 시스템 설계 책까지.. 매일 조금씩 다 하다 보니 하나를 끝까지 밀어붙이는 힘이 부족했다.

무조건이라고 적어놓고 지키지 못한 건 반성해야 한다.

> 다음 스프린트에서는

1. 강의는 하루에 한 섹션이라도 무조건 듣기
2. 단디에서 내가 맡은 기능은 미루지 않고 끝내기
3. 이력서는 지금 상태 그대로라도 계속 업데이트하기

이번에 처음으로 현재 상태의 이력서를 써봤는데, 생각보다 쓸 게 없었다. 쓸 게 많아지도록 다음 스프린트도 그냥 하자.
